🧸 베베픽 여러 이름 후보 감시 v2.3.2

상품코드가 없어도 인형 이름을 최대 20종 미리 등록! 그중 먼저 판매 가능해진 1종을 골라 최종 주문 확인창까지만 자동 진단해.

주문번호를 생성하지 않고, 3분 결제 화면도 띄우지 않는 테스트 전용 버전이야. 기존 실제 주문용 v2.3은 별도로 유지돼.

사용 방법

  1. 아래 북마크 코드 복사를 누르고 PC 크롬 북마크 URL에 붙여넣어.
  2. 베플+ 또는 베베픽 공식 홈페이지에 로그인해.
  3. 기존 자동주문 도우미가 열려 있다면 새로고침 후 v2.3.2 북마크만 실행해. 진단 v2.2.3과도 동시에 사용하지 않는 걸 권장해.
  4. 미공개 신상 이름 후보에서 인형 이름을 정확히 입력하고, 후보 수량과 낱개/풀박스 단위를 설정한 뒤 ＋ 이름 후보 등록을 눌러. 최대 20종 가능!
  5. 여러 이름을 등록하고 ▲/▼로 우선순위를 정해. 후보가 있는 동안 일반 SKU 장바구니 대신 여러 이름 후보 모드가 작동해. 후보를 모두 삭제하면 기존 SKU 선택 모드로 돌아가.
  6. 개봉·보관 옵션과 서버 확인 주기를 정해. 기본 서버 확인 주기는 8초야.
  7. 🔎 OFF → ON 감지 테스트 시작을 누르고, 크롬 탭을 화면에 표시한 상태로 유지해.
  8. 공식 주문 접수 ON 때 전체 이름이 정확히 일치하는 SKU가 하나이며 재고가 판매 가능하면, 등록 순서대로 가장 우선하는 1종만 자동 연결해 최종 확인창까지 이동한 다음 멈춰. 주문 확정은 누르지 않아.
  9. 보라색 접힌 도우미 버튼을 눌러 ⏱️ 구간별 속도 기록을 열고 JSON 기록을 저장하거나 복사해.

안전한 이름 매칭 규칙

이름은 띄어쓰기만 무시하고 전체 이름이 똑같아야 해. 예를 들어 ‘메이메이 서프라이즈’와 ‘메이메이 서프라이즈파티’는 다른 상품이야. 등록 후보 이름으로 발견된 SKU가 여러 개라면 해당 후보는 자동 선택하지 않아. 일부 후보가 품절이어도 다른 후보가 판매 가능하면 그중 하나로 진행해.

20종 동시 구매는 아님! 여러 후보 중 1종만 선택해. 등록된 후보 모두가 주문 접수 때 판매 불가이면 계속 대기하고, 새 홈페이지 공개 상품 목록에 등장하지 않은 인형은 아직 SKU를 확인할 수 없어.

어떤 상태를 따로 기록하나?

홈페이지 방송 표시 ON/OFF와 서버 주문 접수 ON/OFF를 분리해 시각을 기록해. 주문 가능 신호는 주문 접수 ON만 인정해. 이름 후보 발견·공식 SKU 연결·주문바/버튼 표시, 장바구니 열기, 옵션 확인, 1차 확인창과 최종 확인창 도착 시각도 별도로 남겨.

안전 경계: 이 테스트 코드에는 최종 주문 확정 클릭, 주문 생성 API, 결제 화면 자동 이동 기능이 없어. 이름 후보 감시 모드도 동일하게 보호돼. 다만 실제 사이트의 장바구니 구성은 주문 접수 ON 이후 변경되고, 개봉·보관의 1차 확인 동의는 자동 진행해. 이미 담아둔 장바구니를 대체해야 하면 먼저 확인을 요청해.

기본 조회 간격은 8초이며, 서버 ON을 감지하더라도 홈페이지 화면이 아직 닫혀 있으면 자동 진행되지 않을 수 있어. 전체 페이지 새로고침은 자동으로 하지 않아. 백그라운드 탭에서는 감시를 멈추므로 테스트 중 브라우저를 최소화하지 말아줘. 공식 사이트 접근 제한을 우회하지 않아.

속도 기록은 브라우저 세션에만 저장하며, 쿠키/토큰/주소/전화번호/주문번호는 저장하지 않아. 실제 주문이 아닌 상태 변화 및 화면 진행을 확인하는 용도야.
