⏱️ 베베픽 자동주문 범용 v2.3

여러 인형·수량 선택 + 자동 확인 + 결제 직전 정지

한 몰에서 여러 인형/낱개·풀박스/수량을 고른 다음, 공식 재고가 모두 준비될 때까지 기다려. 개봉·보관 옵션을 미리 정해 두고, 명시 동의한 경우에만 공식 주문 확인과 주문 생성까지 진행해. 페이앱 결제창은 자동으로 열지 않아.

설치 방법

  1. 아래 북마크 코드 복사를 눌러.
  2. PC·갤럭시 크롬에서 새 북마크를 만들고 북마크 주소를 복사한 코드로 바꿔.
  3. 베베픽 플러스 또는 베베픽 주문 페이지에 로그인해 둬.
  4. 기존 v2.2.2 등 주문 도우미가 떠 있다면 공식 페이지를 한 번 새로고침하고, 새 v2.3 북마크를 실행해.
  5. 인형 검색 → 구매 단위/수량 → ＋ 인형 추가를 반복해 여러 상품을 목록에 담아.
  6. 개봉·보관 옵션을 선택해 (한 주문의 전체 상품에 동일하게 적용).
  7. 무전송 시험을 유지한 채 먼저 시험해. 실제 주문 생성까지 원할 때만 공식 동의 2단계 및 최종 주문 자동 클릭을 켜고 무전송 시험을 끈 뒤 상세 내용을 확인하고 승인해.
  8. 결과는 도우미 아래 ⏱️ 자동주문 구간별 속도 기록에서 확인해. 복사하거나 JSON으로 저장할 수 있어.

기록되는 단계

서버 조회 시간 · 최초 판매 가능 발견 · 장바구니 준비 · 재고+주문 조건 충족 · 공식 화면 반영 대기 · 장바구니 열기 · 주문 확인창 진입 · 무전송 시험 종료

안전장치: 무전송 시험 기본, 수량/재고/장바구니 재검증, 주문 1회 클릭·중복 방지. 기존 주문의 보관/배송 방식 변경 경고나 사이트 제한이 감지되면 자동 중단. 결제 승인·페이앱 실행은 하지 않아. 로그의 DOM 클릭 기록은 주문 접수 성공을 의미하지 않아.

결제 직전 화면이 나오면 도우미 창을 자동으로 접고 공식 결제 버튼 쪽으로 스크롤해. 크롬 창 자체를 운영체제 작업표시줄로 최소화하는 기능은 아니야. 백그라운드에서는 안전상 감시/확인 동작이 중지될 수 있어. 실제 사이트의 접근 제한을 우회하지 않으며, 저장된 주문 생성 전에는 구매가 완료된 것이 아니야.

속도 로그는 브라우저 같은 탭에만 저장돼. 쿠키·인증 토큰·주문번호는 담지 않아.
