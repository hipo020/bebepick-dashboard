🧸 베베픽 범용 자동주문 v2.3

여러 인형 감시 · 품절 제외 · 한 번의 묶음 주문 · 주문창 자동 이동

감시할 인형을 여러 개 추가하면 공식 서버에서 주문 가능한 인형만 골라 한 번의 장바구니에 담아 공식 주문창으로 이동해. 품절인 인형은 자동 제외돼.

설치 및 사용

  1. 북마크 코드 복사를 눌러 크롬 북마크 주소로 등록해.
  2. 베베픽 플러스 또는 베베픽 공식 페이지에서 실행해. 다른 버전 도우미가 열려 있으면 대기를 중지한 뒤 페이지를 새로고침해야 해.
  3. 위쪽 ＋ 인형 추가를 펼쳐 검색하거나 코드를 적용하고, ＋ 등록을 눌러 감시 목록에 추가해. 각 상품은 기본 1개 또는 풀박스 1세트야.
  4. 감시 목록을 확인하고 공통 개봉·보관/발송 옵션과 서버 확인 주기를 설정해.
  5. 처음에는 무전송 시험 ON으로 확인해. 실제 자동주문을 원하는 경우 기존과 같이 자동 클릭 ON + 무전송 OFF + 명시 동의가 필요해.
  6. 재고가 확인되면 큰 창이 상단 작은 펼치기 버튼으로 접히고, 공식 장바구니·주문 확인창 버튼 쪽으로 자동 스크롤해. 결제 승인은 직접 진행해.

⚠️ 주문은 한 번만 생성하도록 시도해. 여러 제품을 다른 시각에 각각 반복 주문하는 기능은 아니야. 첫 구매 가능한 상품 묶음을 기준으로 진행하며, 재고·가격·사이트 검증 결과에 따라 실패하거나 일부 상품이 제외될 수 있어. 앱이 다른 몰에 담긴 장바구니는 변경하지 않지만, 현재 몰 장바구니를 교체하려면 대기 시작 전에 확인을 받아.
⏱️ 조회는 등록한 인형 수와 무관하게 기존 상품 목록 RPC 한 번을 공유해. 속도 기록도 계속 제공해. 도우미를 줄이고 스크롤한다고 최종 결제 승인을 자동으로 진행하지는 않아.
