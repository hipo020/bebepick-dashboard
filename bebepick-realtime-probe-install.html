🔎 베베픽 공식 사이트 실시간 신호 진단

재고·주문 상태를 **더 빠르게 감지할 수 있는지** 확인하는 읽기 전용 시험 도구야. 실제 주문을 만들거나, 장바구니·개봉·보관 설정을 변경하지 않아.

설치하기

  1. 아래 북마크 코드 복사를 눌러.
  2. 갤럭시 크롬 또는 PC 크롬에서 북마크 하나를 만들고 주소 부분을 아래 코드로 바꿔.
  3. 베베픽 /live 또는 플러스 /plus에 접속하고, 그 북마크를 눌러.
  4. 화면 아래 진단창이 뜨면 관찰할 SKU(예: D796)를 선택적으로 입력해. 약 1~2분 정도 사이트가 스스로 갱신되는지 관찰해.
  5. 진단 결과 복사를 눌러 이 채팅에 붙여넣어 줘.

✅ 공식 상품/주문 RPC를 이 도구가 따로 반복 조회하는 횟수: 0회
✅ 공식 앱 코드(app.js)는 사용 중인 페이지에서 한 번 읽거나 브라우저 캐시에서 가져올 수 있어.
✅ 토큰·쿠키·이름·주문번호·알림 원문은 진단 결과에 포함되지 않아.
⚠️ 분석 결과에 Realtime 코드가 보이더라도 실제 재고 실시간 수신이 가능하다고 단정하지 않아. 실제 재고 변경 이벤트가 있어야 검증 가능해.
