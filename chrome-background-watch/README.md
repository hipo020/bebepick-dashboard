# 베베픽 PC 백그라운드 보조 감시 v0.1 (실험)

기존 자동주문 v2.4를 그대로 사용하며, Chrome MV3 확장 프로그램이 주문 접수와 재고의 **공개 정보만** 확인한다. 공식 주문 버튼·결제 버튼은 확장 프로그램에서 클릭하지 않는다.

## 설치

1. 이 폴더의 manifest.json, background.js, bridge.js, checks.js를 PC의 같은 폴더에 저장한다.
2. PC 크롬에서 `chrome://extensions` → 개발자 모드 ON → **압축해제된 확장 프로그램을 로드합니다** → 저장한 폴더를 선택한다.
3. 베베픽 공식 /live 또는 /plus 탭을 새로고침한다.
4. [기존 v2.4 설치 페이지](https://hipo020.github.io/bebepick-dashboard/bebepick-quick-order-v24-install.html)에서 북마크 도우미를 실행한다.
5. 인형/옵션 설정 → **PC 백그라운드 보조 감시** 체크 → 대기 시작 → 크롬 창을 앞으로 가져오는 데 동의한다.
6. 시험은 우선 **무전송 시험 ON**으로 진행하고 결과를 확인한다. v2.4 실제 주문은 별도의 명시적 사용자 동의가 필요하다.

## 동작

- 현재 화면이 보이면 v2.4의 5~60초 설정대로 감시한다.
- 화면이 숨겨지면 확장 프로그램의 별도 확인이 동작한다. **Chrome 알람 최소 30초, 추가 지연 가능**. 빠른 품절 상품은 이 간격 사이에 놓칠 수 있으므로 5초 보장이라고 안내하지 않는다.
- 주문 창 ON + 선택한 SKU 전부 판매 가능(ALL), 또는 이름 후보 중 한 종 판매 가능(ANY)을 공개 RPC에서 확인한 경우에만 공식 베베픽 탭을 앞으로 가져온다.
- 탭이 활성화되면 v2.4에 **재확인 요청**을 보내고, 기존 코드가 공식 서버·재고·주문바 DOM·수량·옵션·동의 조건을 다시 검사한다.
- 크롬 종료/OS 절전/화면 잠김에서 실행 보장 없음. 브라우저를 재시작해도 자동으로 다시 켜지지 않는다.
- 로그인 계정 전용 상품은 공개 정보만으로 판단하지 못할 수 있다. 우회 시도 없이 감시를 보류한다.
- 접근 제한 401/403이면 감시를 해제하고 429이면 2분 이상 쉰다. 다른 인증이나 비공개 서버 접근은 사용하지 않는다.
- 선택된 탭 하나의 도우미가 멈추거나 페이지에서 나가면 확장 감시도 중단된다.
- 아직 **실제 OFF→ON 라이브와 자동주문 E2E를 검증하지 못한 실험 버전**이며 모바일에는 적용되지 않는다.

## 구성

- `checks.js`: 상품명 완전 일치·SKU·구매 제한·공식 공개 주문창 판단
- `background.js`: 공개 조회와 Chrome 탭 활성화(최소 30초 주기)
- `bridge.js`: 기존 도우미와 확장 사이의 요청 연결
- `manifest.json`: 확장 권한

## 테스트

`node --test tests/chrome-background-watch.test.cjs`

권한: 공식 베베픽 사이트 및 공개 Supabase 주소 읽기, 탭 활성화, 세션 내 감시 정보, Chrome 알람. 계정 토큰·주문번호를 확장 프로그램으로 보내거나 저장하지 않는다.
