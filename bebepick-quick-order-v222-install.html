⏱️ 베베픽 자동주문 범용 v2.2.2

품절 대기 + 공식 주문창 진입 + 구간별 속도 기록

v2.1의 자동주문·품절대기 동작은 유지하고, 재고 처음 확인한 시간부터 주문 확인창으로 넘어가는 데 걸린 시간을 기록하도록 추가했어.

설치 방법

  1. 아래 북마크 코드 복사를 눌러.
  2. PC·갤럭시 크롬에서 새 북마크를 만들고 북마크 주소를 복사한 코드로 바꿔.
  3. 베베픽 플러스 또는 베베픽 주문 페이지에 로그인해 둬.
  4. 기존 범용 v2.1이 이미 떠 있다면 공식 페이지를 한 번 새로고침하고, 새 v2.2.2 북마크를 실행해.
  5. 구매할 상품·옵션을 고른 뒤 무전송 시험 체크 유지, 대기 시작을 눌러.
  6. 결과는 도우미 아래 ⏱️ 자동주문 구간별 속도 기록에서 확인해. 복사하거나 JSON으로 저장할 수 있어.

기록되는 단계

서버 조회 시간 · 최초 판매 가능 발견 · 장바구니 준비 · 재고+주문 조건 충족 · 공식 화면 반영 대기 · 장바구니 열기 · 주문 확인창 진입 · 무전송 시험 종료

주의: 무전송 시험이 기본값이고, 최종 주문 생성은 기존과 같이 별도 설정 및 명시 동의가 필요해. 기록된 DOM 클릭은 주문 접수를 의미하지 않아. 실제 재고가 풀린 정확한 시각은 확인할 수 없고, 최초 판매 가능 상태를 우리 도우미가 관측한 시각부터 측정해.

측정 결과는 브라우저의 같은 탭에 보관되고, 자동 서버 업로드는 하지 않아. 페이지 이동/새로고침 후 마지막 기록을 다시 볼 수 있어. 탭 종료 후에는 사라질 수 있으니 필요한 기록은 JSON으로 저장해 줘.
