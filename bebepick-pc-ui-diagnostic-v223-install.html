🧪 베베픽 PC 주문창 갱신 진단 v2.2.3

공식 홈페이지가 닫힘 → 열림 상태로 바뀔 때 서버와 화면의 시간이 다른지 비교하는 읽기 전용 도우미야.

안전: 주문 버튼, 장바구니, 동의/결제 단계를 누르지 않아. 서버의 주문 상태와 상품 목록은 조회만 해. 기존 실주문용 v2.2.2 도우미와 동시에 실행하지 마.

PC 크롬에서 설치하기 (처음 한 번)

  1. 아래 진단 북마크 코드 복사를 눌러.
  2. 크롬에서 베베픽 플러스 공식 페이지를 열고 Ctrl + D로 북마크를 하나 만들어.
  3. Ctrl + Shift + O로 북마크 관리자를 열어 방금 만든 북마크의 수정을 선택해.
  4. 북마크 이름은 베베픽 PC 진단으로, URL(주소)은 복사한 코드를 통째로 붙여넣고 저장해.
  5. 다시 베베픽 공식 홈페이지 탭으로 돌아와서 북마크바의 베베픽 PC 진단을 클릭하면 진단 창이 나타나.

북마크 주소(URL)에 넣는 코드야. 주소창에서 실행하지 않아도 돼.

진단할 때

  1. 원하면 상품 코드(예: D706)를 입력하고 조회 간격은 8초 권장으로 둬.
  2. 주문 접수가 닫혀 있는 상태에서 진단 시작을 눌러.
  3. 나중에 서버가 열리면 서버 ON, 상단 LIVE/주문 표시, 버튼 enabled의 변화 시간이 각각 기록돼.
  4. 중지 → JSON 저장을 눌러 나온 파일을 이 채팅에 보내줘.

Chrome에서 팝업/코드 실행이 막히면 복사한 북마크 URL이 javascript:로 시작하는지 확인해. 사이트 새로고침 시 진단은 종료돼.

기존 실주문판은 별도: v2.2.2 자동주문 설치. 이 페이지의 v2.2.3은 실주문판이 아니라 PC 진단 전용이야.
