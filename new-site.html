사이트 설정, TEST 표시, 테스트 상품 문구, 결제·주문·회원가입 관련 코드 표식처럼 중요한 변화는 신규 홈페이지 전용 ntfy 토픽으로 보내. 해당 토픽을 구독하지 않으면 휴대폰 알림은 오지 않아. 단순 JS·HTML 수정은 기록만 남겨.

처음 확인했을 때는 기준값만 저장하며 알림을 보내지 않아. 회원가입 가능 여부, 실제 결제 성공, 로그인 뒤 상품·가격은 공개 코드만으로 단정하지 않아.

전체 감시와 푸시 알림은 서버에서 따로 켜고 끌 수 있어. 이 화면은 읽기 전용이라 다른 방문자가 설정을 바꿀 수 없어.
