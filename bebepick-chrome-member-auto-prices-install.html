🧸 베베픽 회원 가격 자동 확인

갤럭시·PC 크롬용 · 로그인한 공식 홈페이지에서 30초마다 회원 가격 읽기 · 재고판과 탭 간 연결

① 크롬 북마크 코드 복사

코드를 준비하고 있어…

본인 계정 로그인 토큰이나 비밀번호를 입력할 필요는 없어. 코드는 공식 사이트의 회원 상품 조회만 사용해.

② 북마크에 설치

  1. 크롬에서 아무 페이지나 북마크해.
  2. 북마크 편집에서 이름을 베베픽 자동가격으로 바꿔.
  3. 북마크 URL을 지우고 복사한 코드를 붙여 넣어 저장해.
  4. 로그인된 베베픽 플러스 또는 베베픽 본점을 열어.
  5. 주소창에 베베픽 자동가격을 입력하고 검색 제안의 북마크 항목을 눌러 실행해.

갤럭시 크롬은 주소창에 javascript:를 직접 입력하면 보안상 잘릴 수 있어. 저장된 북마크를 선택해야 해.

③ 자동 조회 + 재고판 연결

실행 즉시 회원 가격을 조회하고 30초마다 자동 갱신해. 표시된 도구에서 📊 재고판 연결을 누르면 새 탭으로 재고판을 열고 최근 회원 가격을 보여줘.

자동 작동 범위
크롬의 베베픽 탭이 살아 있는 동안만 갱신해. 갤럭시에서 화면을 끄거나 백그라운드로 보내면 브라우저가 시간을 늦추거나 실행을 중지할 수 있어. 서버나 ntfy에 회원 가격을 올리는 기능은 아직 포함하지 않았어.
