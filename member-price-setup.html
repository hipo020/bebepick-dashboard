⏳
서버용 회원 가격 연결 전 현재 24시간 자동 가격 수집은 작동하지 않아. 아래 단계가 검증될 때까지 로그인 연결 버튼을 제공하지 않아.

표시는 2026년 11월 5일 점검 결과 기준이야. 이 공개 안내 페이지는 계정별 상태를 조회하거나 개인 정보를 표시하지 않아.

안전하게 연결하기 위한 순서

  1. 회원 가격 전용 인증 권한 확인

    현재 베베픽은 외부 앱에 가격 조회만 위임하는 방식을 제공하지 않아. 본계정 세션은 주문 권한도 포함할 수 있어.

  2. 격리된 서버 로그인 환경 보안 검증

    직접 로그인할 수 있는 별도 환경, 서버 내 암호화 보관, 세션 해제, 단일 갱신 작업자와 요청 제한을 모두 확인해야 해.

  3. 가격 조회만 시험

    상품 코드, 낱개 가격, 풀박스 가격과 확인 시각만 처리하고 회원정보·주문·결제 요청을 차단해.

  4. 개인 전용 화면과 알림 연결

    회원 가격을 공개 GitHub Pages 화면이나 기존 공개 ntfy 토픽에 그대로 노출하지 않아. 개인 인증 보호가 준비된 뒤에만 연결해.

계정 보호 원칙

  • 비밀번호·인증번호·쿠키·액세스/갱신 토큰을 채팅이나 이 페이지에 입력하지 않아.
  • 공식 로그인 화면에서 직접 인증하고, 본계정의 주문 가능 권한을 정확히 이해한 다음에만 서버 세션 보관 여부를 결정해.
  • 사용 중지 시 서버 세션·수집 작업·가격 데이터의 폐기 여부를 확인할 수 있어야 해.
  • 기존 공개 재고 30초 감시, 인형 사진 알림과 주문 자동화는 변경하지 않아.

지금 사용할 수 있는 기능

브라우저 가격 확인: 네가 베베픽에 직접 로그인한 탭에서 상품 가격만 확인하는 도구는 이미 있어. 다만 이 도구는 탭을 닫거나 컴퓨터를 끄면 멈추며 서버 24시간 연동은 아니야.

브라우저 가격 확인 도구 베베픽 공식 로그인 화면

공식 사이트에서 로그인하는 것만으로 우리 재고판의 서버 연결이 이루어지지는 않아.
